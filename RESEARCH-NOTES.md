# No Human Allowed MMO — как делают похожее: бестпрактис и грабли (ресёрч)

Сводка веб-ресёрча по трём направлениям. **Важное:** наш текущий каркас (таблица `intents` +
единый авторитетный тик-луп + целочисленная физика) — это и есть документированный бестпрактис
(AI Town + Gaffer). Ниже — что докрутить.

## 1. Миры для ИИ-агентов / multi-agent сим (AI Town, Generative Agents, Project Sid, Voyager)
**Авторитетность и детерминизм:**
- Агенты шлют **намерения, не состояние** (как у нас): append-only `inputs(tick, agent, seq, action, payload)`;
  движок — единственный мутатор. Читаём pending → применяем правила → пишем дельту.
- **Один авторитетный step-loop на мир/шард**, с «generation number» как fence (бамп поколения → старый
  ин-флайт прогон падает) — в PG это advisory-lock / колонка `worlds.generation` в транзакции коммита.
- **Батчить много тиков в один DB-step** (AI Town: step ~1/с, внутри ~60 тиков) — одна транзакция
  амортизирует много тиков. Главный рычаг пропускной способности для БД-мира.
- Детерминизм — жёсткий контракт: целые/fixed-point (у нас уже так; float ломает детерминизм по
  компиляторам/архам), фиксированный timestep, RNG из `(tick, entity_id)`, тотальный порядок применения
  intents (sort by seq). Хранить **per-tick хеш состояния** (`tick_hashes`) → ловить недетерминизм в CI
  реплеем + давать зрителям tamper-evident аудит. Состояние = fold(rules, seed, inputs[0..t]).

**API наблюдений:** агенту — курированный **observation** (не вся БД): self, видимые сущности/тайлы в
зоне интереса, недавние события, инвентарь/энергия. Частичная наблюдаемость = и реализм, и анти-чит.
Валидация действий — в движке (дотянулся? по карману? легально?), на нелегальное — структурный фидбэк
(как Voyager: ошибки выполнения + самопроверка возвращаются агенту → он чинится).

**Асинхронная когниция:** тик-луп НИКОГДА не ждёт LLM. Агент «думает» между тиками (одна ин-флайт
операция на агента), решение прилетает будущим intent. Расцепляет часы мира и латентность модели.

**Лимиты/честность:** (а) внутриигровая энергия/экономика (Sid: ~20% «налоги», валюта) бьёт по
поведению диегетически; (б) внешние бюджеты на токены/вызовы/время — без «definition of done» агенты
жгут токены бесконечно. 1 intent на агента на тик максимум.

**Анти-сговор/честность:** LLM-сговор реален (явные картели, тацит, **стеганография в безобидных
сообщениях**) → структурировать канал связи (типизированные сообщения вместо free-text где можно),
логировать ВСЕ сообщения агентов, governance > честность (правила — код, «конституцию» агенты могут
голосовать менять, но не обойти). Честность между разными моделями/бюджетами → **лиги/дивизионы** +
гандикапы (Sid: слабые модели «проваливались полностью»); одинаковый интерфейс наблюдений/действий всем.

**Масштаб:** interest management обязателен (наивная синхронизация всем — O(N²), стена MMO): сетка
клеток, агент подписан на свою+соседние, хэндофф на границах; шардинг по регионам (Sid упёрся ~1000
агентов в отзывчивость сервера). Расцепить **частоту когниции от частоты физики** (PIANO): физика
каждый тик, дорогое планирование агента — раз в K тиков; при отставании резать когницию, не правила.

**Эмерджентность:** память (recency-decay + importance 1–10 + relevance-cosine, нормировать и взвесить —
ложится на PG+pgvector) + рефлексия + планирование + **библиотека навыков** (Voyager: успешные
программы по эмбеддингу описания). Засеять роли/драйвы (Sid: фермер/шахтёр/страж за ~20 мин при
наличии соц-модулей).

**Грабли:** бесконечные циклы (агент сотни шагов повторяет провальное действие) → **движок-энфорсед**
детект повторов в окне последних ~3 действий + хард-капы + память о прошлых провалах; каскады
галлюцинаций (малая доля «отравляет» вниз по течению) → грундить наблюдения авторитетным состоянием
каждый тик, структурный канал связи; вырожденные равновесия/коллапс → штрафы governance + репутация/санкции;
слабая пространственка → давать **символические** аффордансы (pathfind-to, adjacency, именованные локации),
не сырую геометрию. **Зрелищность для людей:** буфер истории по тикам (как AI Town `HistoricalObject`)
для гладкой интерполяции + слой «почему» (извлечённые воспоминания / текущий план / последний intent
агента). «Совет человека» = обычный низкоприоритетный intent в логе, агент волен не учесть.

## 2. Part-based конструкторы машин (KSP, From the Depths, Space Engineers, Trailmakers, Factorio…)
**Представление:** три школы — воксель/блок-сетка (Factorio, Space Engineers, Scrap Mechanic),
узлы+джоинты/балки (KSP, Besiege), порт/аттач-системы. Поведение машины выводится либо посимуляцией
каждой детали (дорого, нестабильно), либо **суммой констант деталей в агрегаты целой машины** (дёшево).
**Берём второе.**
- KSP **drag cubes**: сопротивление = табличный лукап 6 граней + взвешенная сумма с перекрытием при стыковке.
- From the Depths — полностью **лумпированная модель**: трение по длине, подъёмная сила крыла ~линейна
  по скорости с капом, **drag приложен в центр масс → не создаёт паразитного момента**.
- Space Engineers — **вся тяга в центр масс** → нет штопора.
- Аркада: `drive_force = torque · gear / wheel_radius`, макс. скорость в точке баланса сил.
**Грабли → решения:** «Кракен» KSP (стопки джоинтов копят ошибку float) → **трактовать всю машину как
одно твёрдое тело, аэро/силы на всю машину**; цена на масштабе → CPU-budget на деталь (Trailmakers)
вместо лимита числа деталей; нестабильность/клиппинг → нет джоинт-солвера в упрощёнке.
**Для нашего лёгкого движка:** валидировать граф деталей один раз → схлопнуть в одно тело → сумма
целочисленных констант в `{mass, com, total_thrust, total_lift, power, wheels→drive, drag}` → замкнутые
формулы (v_max из баланса, «летит» если lift·v² ≥ g·mass). Всё аналитически → агента можно оценивать без
прогона сим. (Детали — в [PHYSICS-VEHICLES.md](PHYSICS-VEHICLES.md).)

## 3. Процедурная генерация
**Бестпрактис:** слоёная генерация (высоты→климат→биомы→регионы/ландмарки→ресурсы→связность), биомы из
нескольких независимых полей (Уиттакер), **рукотворные якоря/сет-писы** в проц-пространстве, WFC только
для маленьких структурных зон, конечные кластерные залежи через **density-modulated Poisson-disk**,
привязка ресурсов к биомам, **flood-fill гарантия связности**, детерминизм по хеш-сидам, веса вместо
равномерного рандома. **Грабли:** «процедурная овсянка» (single-pass + сырой шум + равномерность),
несвязные/непроходимые состояния (CA-пещеры, провал WFC), перф на главном потоке, «бесконечно, но пусто».
(Детали — в [WORLD-PROCGEN.md](WORLD-PROCGEN.md).)

## Что докрутить в нашем каркасе (приоритет)
1. `inputs`/intents — добавить `seq` + тотальный порядок; per-tick хеш состояния (`tick_hashes`).
2. Батчить N тиков на один DB-step; generation-fence на мир.
3. Курированный observation + валидация + структурный фидбэк агенту; асинхронная когниция как future-intent.
4. Энергия/бюджеты + детект циклов (движок-энфорсед) + лог сообщений.
5. Interest-management по клеткам + шардинг по регионам (заранее).
6. Память pgvector + библиотека навыков; буфер истории + слой «почему» для зрителей.
7. Сборка машин (PHYSICS-VEHICLES) + слоёный процген (WORLD-PROCGEN).
